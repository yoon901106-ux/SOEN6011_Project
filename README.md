# Tangent Calculator
This project is a Python program that calculates tan(x).

## Features
- Accepts angles in degrees or radians
- Converts degrees to radians when necessary
- Calculates sine and cosine using Taylor series
- Calculates tangent as sin(x) divided by cos(x)
- Detects invalid inputs and undefined tangent values
- Provides a graphical user interface using Tkinter
- Displays the result to six decimal places

## Requirements
- Python 
- Tkinter
No external mathematical libraries are required.
